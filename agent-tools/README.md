# Spend Agent 新人任务手册

目标：让第一次处理 Spend 的 Agent 在已授权范围内完成只读检查，交付可复核的证据和未解决事项。各入口按需使用，不要求串联；不调用写工具、不创建外部报表或上传数据。案例中的占位符不是业务事实。

## 先收集什么

记录业务目标和预期交付、客户及指定 Click URL（或足以在该客户范围内查找的线索）、日期范围及业务时区、异常现象或需对比的指标、操作者可用身份/权限、已有证据及其来源。日期区间注明是否含首尾。缺客户范围、无法确认实体归属或缺任务必需日期时停止并列缺项；不能为了演示选择其他客户。先检查身份和可用能力，不使用他人凭据，不扩大权限。

## 基础口径

- **Net / Gross / Margin**：Net 和 Gross 是不同口径的金额，具体含义与计费规则应以客户合同及当期业务资料为准。某些已核实案例中 Margin 以 Gross 为分母，计算 `(Gross - Net) / Gross`；Gross 为零时该比率不可计算。不能把这一公式或某个费率强套所有合同，也不能在未知分母时比较百分比。
- **Spend Date / Created At**：Spend Date 是记录归属的消费日期；Created At 是创建记录的时间。按消费日查数不能证明该期间创建了多少记录。Spend Lens 指南的查询按 UTC Spend Day，其他系统的时区须核实。
- **实体 ID**：先确认客户、Click URL 及其归属。Femini 使用的 legacy Click URL 与内部实体 ID 有不同含义；不同系统的 Client、Campaign、Partner 等内部 ID 不可直接互换。
- **币种、来源、刷新**：逐项核实币种及金额单位，不混加不同币种；记录每个数字的数据源、查询时间、数据覆盖和刷新时间。刷新时间没有返回就写未知；存储快照不等于外部实时值。
- **null / 0 / 无记录**：`null`、空结果或缺失日期表示缺失或未返回，不能自动当作零、漏录或正常；明确返回的数值 `0` 才是该字段记录为零。

先读[系统与口径地图](spend-system-map.md)，再按问题选择以下指南；新补充指南均为静态源码/文档核对，尚未实测。

## 根据问题选路

| 业务问题 | 先走哪里 | 能力及边界 |
|---|---|---|
| 某天缺数或金额异常 | [缺失与异常排查](workflows/missing-and-anomaly-triage.md) | 分层核对事实、任务、历史规则与审计；每日任务错误可能需查看 Admin 页面。 |
| Admin 记录、创建时间及变更 | [Admin Workspace](admin-workspace/README.md) | 使用本人已有权限并核实分页；创建时间不是创建人。 |
| Client Report 与 Admin 对账 | [FeedMob Reporting](feedmob-reporting/README.md) | 同实体、日期、币种及层级比较；含 L0 时单独核实全量来源。 |
| 检查已录入 Spend、调查异常或与来源差异 | [Spend Lens](spend-lens/README.md) · [七日请求案例](spend-lens/examples/seven-day-review.md) | 本人授权账号及浏览器；检查 Admin L1，外部源未返回时不能完成对账。 |
| 查看指定 Click URL 的日度数据或多源快照 | [Femini](femini/README.md) · [单日请求案例](femini/examples/daily-snapshot.md) | 本人已授权原生工具及实际 schema；仅有网页时只能核对页面可见字段。 |
| 计费试算 | [Femini 试算前提](femini/README.md) | 先核实方法、费率、生效期、事件来源和路由；缺项即停止。试算尚未验证。 |
| 补录、修改或复杂结算 | [受控写回参考](workflows/controlled-writeback.md)，列为后续场景 | 本期不写入；合同规则、权限、审批和实际流程需另行确认。 |

若需跨系统对照，先分别核实实体映射、日期、币种、分母、来源和刷新；即使数字相同也不自动证明外部对账一致。

## 按当前能力启动

- **只有浏览器**：本人可进入 Spend Lens 时按其流程检查；Femini 网页仅核对可见字段，记录页面与时间，不称为原生工具验证。
- **Admin Workspace 或 FeedMob Reporting 已接入**：按对应指南检查本人身份、实际 schema、对象权限及分页；GET 不自动意味着无副作用。
- **原生 Femini 工具已接入**：检查当前身份、工具是否可发现及实际 schema，再执行只读快照；存在写工具不代表应调用。
- **无权限或无所需工具**：列出缺失的身份、对象权限或能力及可完成的部分；停止受阻步骤，不换账号、不提取网页令牌，也不反复触发凭据提示。

## 可复制的新任务

> 请以我的已授权身份，只读处理以下 Spend 问题：目标 `<检查/差异排查/快照/试算>`；客户 `<客户>`；Click URL 或定位线索 `<ID/线索>`；日期 `<开始—结束，含首尾与时区>`；现象与希望对比的数据 `<现象/指标/来源>`；已有证据 `<链接及时间，若无写无>`；当前可用能力 `<浏览器/已接入原生工具/未知>`。先核实客户归属与能力，按手册选路；不要查无关客户、写入、上传或创建外部报表。以成功、部分完成或受阻报告，列范围、来源、币种、刷新时间、证据、未知项和下一步。缺必要输入请明确列出，不猜测。

## 交付验收清单

- [ ] 任务目标、客户/实体归属、日期/时区、身份和实际使用的能力已记录。
- [ ] 对照原始输出或可见页面，标出来源、币种、覆盖、刷新时间、null/0 和限制；证据仅保存在授权的私有位置。
- [ ] 结论有证据支撑；缺数据或外部对账无法完成时标为部分完成，不把未知当零或一致。
- [ ] 逐项列出已完成、未完成、失败原因和所需下一步；网页核对不冒充原生调用。
- [ ] 未执行生产写入、上传或创建外部报表；试算缺规则时未猜测。

默认流程不调用 `partner_net_spends` 及其分支：部分 GET 会创建外部报表，其他网关分支副作用未知。`vendor_managed` 文档乘法与脚本 SQL 除法冲突，待确认；不能作为默认金额算法。
