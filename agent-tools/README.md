# Spend Agent 任务入口

首期范围：查询、诊断和无写入试算。两个产品独立使用，不要求串联；不得修改生产数据。实际可见能力取决于操作者身份、权限、工具配置和服务状态。案例中的占位符不是业务事实。

| 任务 | 入口 | 条件 |
|---|---|---|
| 检查已录入 Spend、异常与根因 | [Spend Lens 操作指南](spend-lens/README.md) · [七日案例](spend-lens/examples/seven-day-review.md) | 本人 FeedMob 账号和可操作浏览器；不能直接作为外部 MCP 调用 |
| 查数、多源快照、计费试算 | [Femini 操作指南](femini/README.md) · [日度案例](femini/examples/daily-snapshot.md) | 本人授权的原生 Femini 接入；调用前核对实际发现的 schema |

当需要从异常转入试算，或从快照转入根因调查时，先核对实体、日期、币种、数据源和刷新时间；不要默认口径相同。未来写入属于另一期，须单独授权，本期不调用写工具。
