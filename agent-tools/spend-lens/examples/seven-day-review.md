# 案例：连续七天检查已录入 Spend

此模板中的 `<CLICK_URL>` 为占位符；优先采用任务给定的 legacy Click URL；若未给定，按[指南](../README.md)在本人有权访问的产品对象列表或现有原生只读实体工具中结合任务客户范围筛选、核实归属。无任务客户范围或无法确认归属时停止并列明缺项，不擅选无关客户，也不假定 23567 对所有人可用。打开[指南](../README.md)所述主页，登录后从界面进入新对话，提交：

> 请只读检查 Click URL `<CLICK_URL>` 在 2026-11-03 至 2026-11-09（含首尾）的 Admin net_spends，核实实体和权限，逐日列已有记录、异常、外部源状态及有证据的根因；缺失或未查明请标明。不要创建或触发外部报表、上传、修改数据或执行任何写操作；如需这些操作请停止并说明。

按实际界面展开 “Worked for… · N steps”，逐条展开并加载底层工具结果；无法展开时标记未复核。检查结果是否完成，核对七天覆盖、币种、逐日原始证据、每个外部源状态、异常和原因的证据；把不可用/未确认如实记录。只有私有会话链接可在授权范围保存，不启用分享。若对话仍在运行、因需要报表而停止、权限不足或数据源缺失，要报告实际状态，不能称为通过。
